CHOICES

Cuando trabajas con un motor basado en Choices (gramática cerrada), el sistema es más robusto frente al ruido que el dictado libre. Sin embargo, si el ruido ambiental es fuerte, el motor intentará "forzar" el ruido para que encaje con alguna de tus palabras clave.Para solucionar esto, debes capturar el evento SpeechRecognitionRejected. Este evento se dispara automáticamente cuando el usuario habla (o hay un ruido fuerte) pero el motor determina que lo escuchado no coincide con tus Choices.Captura de ruido con SpeechRecognitionRejectedcsharp// 1. Suscríbete al evento de rechazo junto al de reconocimiento exitoso
recognizer.SpeechRecognized += recognizer_SpeechRecognized;
recognizer.SpeechRecognitionRejected += recognizer_SpeechRecognitionRejected;

// 2. Este evento se dispara si el ruido NO se parece a tus Choices
void recognizer_SpeechRecognitionRejected(object sender, SpeechRecognitionRejectedEventArgs e)
{
    Console.WriteLine("Ruido detectado o palabra no emparentada con las opciones.");
    Console.WriteLine($"Confianza del rechazo: {e.Result.Confidence}");
}

// 3. Este evento se dispara si el ruido SÍ se confunde con una opción (Falso positivo)
void recognizer_SpeechRecognized(object sender, SpeechRecognizedEventArgs e)
{
    // Filtra falsos positivos causados por ruido aplicando un umbral estricto
    if (e.Result.Confidence < 0.75f) 
    {
        Console.WriteLine($"Falso positivo descartado por baja confianza ({e.Result.Confidence}).");
        return;
    }

    Console.WriteLine($"Comando válido detectado: {e.Result.Text}");
}

System.Speech

Al utilizar la librería nativa System.Speech de Windows, tienes acceso directo al motor de reconocimiento local SAPI (Speech API). Este motor es muy sensible al ruido de fondo cuando se usan Choices, pero permite una configuración avanzada para mitigar el problema sin consumir recursos de la nube.Aquí tienes la estrategia definitiva para blindar tu código de System.Speech contra el ruido ambiental.Implementación Completa contra Ruido en System.SpeechEste código configura los tres niveles de defensa: rechazo automático, filtro de confianza estricto y monitoreo de señal defectuosa.csharpusing System;
using System.Speech.Recognition;

public class ReconocedorVoz
{
    private SpeechRecognitionEngine recognizer;

    public void Inicializar()
    {
        // 1. Crear el motor con el idioma del sistema
        recognizer = new SpeechRecognitionEngine(new System.Globalization.CultureInfo("es-ES"));

        // 2. Definir tus Choices de forma robusta (evita palabras de una sílaba)
        Choices comandos = new Choices();
        comandos.Add(new string[] { "iniciar aplicacion", "detener proceso", "cerrar ventana", "mostrar ayuda" });

        GrammarBuilder gb = new GrammarBuilder();
        gb.Append(comandos);
        Grammar gramatica = new Grammar(gb);
        recognizer.LoadGrammar(gramatica);

        // 3. Configurar los eventos clave para el manejo de ruido
        recognizer.SpeechRecognized += Recognizer_SpeechRecognized;
        recognizer.SpeechRecognitionRejected += Recognizer_SpeechRecognitionRejected;
        recognizer.AudioSignalProblemOccurred += Recognizer_AudioSignalProblemOccurred;

        // 4. Configurar la entrada de audio por defecto
        recognizer.SetInputToDefaultAudioDevice();

        // 5. Iniciar reconocimiento continuo
        recognizer.RecognizeAsync(RecognizeMode.Multiple);
        Console.WriteLine("Motor System.Speech listo.");
    }

    // Nivel 1: Filtro de falsos positivos (El ruido se pareció a un comando)
    private void Recognizer_SpeechRecognized(object sender, SpeechRecognizedEventArgs e)
    {
        // System.Speech suele dar falsos positivos con ruido si la confianza es baja
        // Un umbral entre 0.70 y 0.80 es el ideal para Choices locales
        if (e.Result.Confidence < 0.75f)
        {
            Console.WriteLine($"[Falso Positivo] Ruido confundido con '{e.Result.Text}' (Confianza baja: {e.Result.Confidence:F2})");
            return;
        }

        Console.WriteLine($"[Comando Ejecutado]: {e.Result.Text} (Confianza: {e.Result.Confidence:F2})");
    }

    // Nivel 2: Ruido puro detectado (El motor detectó sonido pero no coincide con tus Choices)
    private void Recognizer_SpeechRecognitionRejected(object sender, SpeechRecognitionRejectedEventArgs e)
    {
        Console.WriteLine("[Ruido/Rechazo] Sonido ambiental o palabra no registrada detectada.");
    }

    // Nivel 3: Alertas de Hardware (Saturación o micrófono defectuoso)
    private void Recognizer_AudioSignalProblemOccurred(object sender, AudioSignalProblemOccurredEventArgs e)
    {
        // Esto te avisa si el usuario sopla el micro, está muy lejos o hay estática pesada
        if (e.AudioSignalProblem == AudioSignalProblem.TooLoud)
        {
            Console.WriteLine("[Alerta] Entrada de audio muy alta (Saturación por ruido).");
        }
        else if (e.AudioSignalProblem == AudioSignalProblem.TooNoisy)
        {
            Console.WriteLine("[Alerta] El entorno es demasiado ruidoso para el motor SAPI.");
        }
    }
}

windows forms, auricular/headset

El uso de Windows Forms combinado con un auricular/headset es el mejor escenario posible para el reconocimiento local con System.Speech. Al tener el micrófono cerca de la boca, la relación señal/ruido es excelente, lo que permite implementar controles visuales precisos en tu interfaz y evitar hilos bloqueados.Aquí tienes la solución optimizada para tu formulario, que incluye una barra de progreso para ver el volumen del ruido en tiempo real y actualizaciones seguras en la interfaz gráfica mediante Invoke.Diseño de la Interfaz (UI) sugeridoPara aprovechar este código, añade estos elementos a tu Form1:Un ProgressBar llamado pbVolumen (recomiendo cambiar su color a verde o azul).Un Label llamado lblEstado para ver si es ruido, comando válido o falso positivo.Un ListBox llamado lstComandos para registrar el historial.Código Completo para tu Formulario Windows Formscsharpusing System;
using System.Drawing;
using System.Speech.Recognition;
using System.Windows.Forms;

namespace ReconocimientoVozForms
{
    public partial class Form1 : Form
    {
        private SpeechRecognitionEngine recognizer;

        public Form1()
        {
            InitializeComponent();
            InicializarReconocedor();
        }

        private void InicializarReconocedor()
        {
            try
            {
                // Idioma español nativo de Windows
                recognizer = new SpeechRecognitionEngine(new System.Globalization.CultureInfo("es-ES"));

                // Choices robustos (frases de 2 o más palabras para usar con headset)
                Choices comandos = new Choices();
                comandos.Add(new string[] { "abrir reporte", "guardar cambios", "limpiar pantalla", "salir del sistema" });

                GrammarBuilder gb = new GrammarBuilder();
                gb.Append(comandos);
                Grammar gramatica = new Grammar(gb);
                recognizer.LoadGrammar(gramatica);

                // Eventos clave de System.Speech
                recognizer.SpeechRecognized += Recognizer_SpeechRecognized;
                recognizer.SpeechRecognitionRejected += Recognizer_SpeechRecognitionRejected;
                recognizer.AudioSignalProblemOccurred += Recognizer_AudioSignalProblemOccurred;
                
                // Evento para pintar el medidor de volumen/ruido en el ProgressBar
                recognizer.AudioLevelUpdated += Recognizer_AudioLevelUpdated;

                // Conectar al auricular por defecto y arrancar
                recognizer.SetInputToDefaultAudioDevice();
                recognizer.RecognizeAsync(RecognizeMode.Multiple);

                lblEstado.Text = "Micrófono listo. Esperando comandos...";
                lblEstado.ForeColor = Color.DarkBlue;
            }
            catch (Exception ex)
            {
                MessageBox.Show($"Error al iniciar el motor de voz: {ex.Message}", "Error Hardware", MessageBoxButtons.OK, MessageBoxIcon.Error);
            }
        }

        // Actualiza el ProgressBar con el ruido/voz que detecta el headset en tiempo real
        private void Recognizer_AudioLevelUpdated(object sender, AudioLevelUpdatedEventArgs e)
        {
            // System.Speech se ejecuta en un hilo secundario. Usamos Invoke para no romper la UI de Forms.
            if (this.InvokeRequired)
            {
                this.BeginInvoke(new Action(() => ActualizarBarraVolumen(e.AudioLevel)));
            }
            else
            {
                ActualizarBarraVolumen(e.AudioLevel);
            }
        }

        private void ActualizarBarraVolumen(int nivel)
        {
            // El nivel viene de 0 a 100
            pbVolumen.Value = nivel;
        }

        // CONTROL DE RUIDO NIVEL 1: Falso positivo (Ruido ambiental que mutó en palabra)
        private void Recognizer_SpeechRecognized(object sender, SpeechRecognizedEventArgs e)
        {
            this.Invoke(new Action(() =>
            {
                // Con un headset, si la confianza baja de 0.72 suele ser un suspiro, respiración fuerte o golpe en el cable
                if (e.Result.Confidence < 0.72f)
                {
                    lblEstado.Text = $"Ruido descartado (Confianza baja: {e.Result.Confidence:F2})";
                    lblEstado.ForeColor = Color.OrangeRed;
                    return;
                }

                // Comando exitoso
                lblEstado.Text = $"Comando detectado: {e.Result.Text}";
                lblEstado.ForeColor = Color.DarkGreen;
                lstComandos.Items.Insert(0, $"[{DateTime.Now.ToShortTimeString()}] {e.Result.Text} ({e.Result.Confidence * 100:F0}%)");
                
                // Aquí ejecutas tu lógica según el comando
                ProcesarComando(e.Result.Text);
            }));
        }

        // CONTROL DE RUIDO NIVEL 2: El motor sabe que es ruido o una palabra inválida
        private void Recognizer_SpeechRecognitionRejected(object sender, SpeechRecognitionRejectedEventArgs e)
        {
            this.Invoke(new Action(() =>
            {
                lblEstado.Text = "Sonido o ruido ambiental no reconocido.";
                lblEstado.ForeColor = Color.Gray;
            }));
        }

        // CONTROL DE RUIDO NIVEL 3: El micrófono del headset está saturando o mal posicionado
        private void Recognizer_AudioSignalProblemOccurred(object sender, AudioSignalProblemOccurredEventArgs e)
        {
            this.Invoke(new Action(() =>
            {
                if (e.AudioSignalProblem == AudioSignalProblem.TooLoud)
                {
                    lblEstado.Text = "¡Alerta! Estás hablando muy fuerte o soplando el micrófono.";
                    lblEstado.ForeColor = Color.Red;
                }
            }));
        }

        private void ProcesarComando(string comando)
        {
            if (comando == "salir del sistema") this.Close();
            // Resto de condiciones...
        }

        // Muy importante: Liberar el micrófono si se cierra el formulario
        protected override void OnFormClosing(FormClosingEventArgs e)
        {
            if (recognizer != null)
            {
                recognizer.RecognizeAsyncStop();
                recognizer.Dispose();
            }
            base.OnFormClosing(e);
        }
    }
}
